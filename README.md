The purpose of this repository is to develop a solid understanding of Python through consistent practice and hands-on experimentation.

My main objectives are:

- **Build Strong Foundations:** Understand Python syntax, data types, control flow, functions, data structures, and object-oriented programming.
- **Develop Problem-Solving Skills:** Improve logical thinking and the ability to translate problems into working code.
- **Explore Robotics & AI:** Connect programming concepts with practical applications in robotics, automation, and artificial intelligence.
- **Build Good Development Habits:** Practice writing readable code, debugging, documenting progress, and using Git for version control.

## My Learning Approach

I focus on understanding concepts rather than simply copying code.

My learning process follows these principles:

1. **Learn:** Study a concept and understand how it works.
2. **Practice:** Write code independently to apply what I have learned.
3. **Experiment:** Modify existing code, test different approaches, and explore possible outcomes.
4. **Debug:** Identify errors and understand why they happen.
5. **Apply:** Connect programming concepts to real-world problems, especially in Robotics and AI.
6. **Document:** Record important concepts, exercises, and learning progress.

## Running Python Files

To run a Python file locally:

```bash
python filename.py
```

Depending on your system configuration, you may need:

```bash
python3 filename.py
```
